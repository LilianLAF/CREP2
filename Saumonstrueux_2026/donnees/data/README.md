# donnees/data

Shapefiles des lignes de côtes continentales (Natural Earth, résolution 1:10m).

- `ne_10m_coastline.shp/.dbf/.shx` : géométries des côtes mondiales.

Utilisé pour tracer les contours des continents dans les visualisations cartographiques. Ces fichiers n'ont pas besoin d'être ouverts manuellement.
