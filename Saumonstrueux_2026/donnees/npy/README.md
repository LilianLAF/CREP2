# donnees/npy

Profils atmosphériques prétraités (température, pression en fonction de l'altitude) au format NumPy.

**Note** : les fichiers `grid_lowres_1yr.npy` et `grid_hires_1yr.npy` (dossier `stabilized/`) ont été supprimés pour des raisons de taille. Les profils sont recalculés à la volée par le modèle via le standard atmosphérique US1976.
