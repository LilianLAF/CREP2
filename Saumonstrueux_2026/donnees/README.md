# Donnees du projet 2026

Ce dossier contient les fichiers volumineux separes du code source, conformement aux consignes de rendu.

## Sous-dossiers

- `albedo/` : series et references sur l'albedo
- `Cp_humidity/` : donnees d'humidite des sols et scripts associes
- `data/` : couches geographiques complementaires
- `map/` : shapefiles pour la localisation geographique
- `npy/` : tableaux numeriques precalcules

## Regle

Le code de production (MAIN et modules) doit lire ses ressources depuis ce dossier `donnees/`.
