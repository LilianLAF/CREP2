# donnees/map

Shapefiles des frontières pays (Natural Earth, résolution 1:110m).

- `ne_110m_admin_0_countries.shp/.dbf/.prj/.cpg/.shx` : polygones des pays du monde.

Utilisé par `librairie_puissances.py` et `ZZ_cp.py` pour identifier le type de surface (mer, terre, continent) à une coordonnée donnée, et pour l'affichage des cartes.
