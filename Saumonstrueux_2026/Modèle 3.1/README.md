# Projet Climat 2026

Ce modèle prend en compte pour le calcul de alpha (alpha = "flux sortant atmosphère" / "flux émis terre") l'évolution en fonction des années des GES notamment : CO2, CH4, O3, N20, H2O. On suppose que la concentration en gaz ne dépend pas de l'altitude (répartition homogène des gaz dans l'atmosphère).

Alpha est ensuite appelé dans le code librairie_puissances.
