# CREP2

Ce depot contient les travaux du projet climat (TEDS) sur plusieurs promotions.

## Organisation du depot

- `Chevreaux_brillants_2025/` : rendu precedent (archive de reference).
- `insereznomgroupe_2026/` : dossier de rendu principal 2026.
- `Requirements.txt` : dependances Python minimales.

## Format de rendu 2026 applique

Le dossier `insereznomgroupe_2026/` est organise pour respecter le cahier des charges:

- un `README.md` principal,
- la synthese (fichier `synthese.pdf` a fournir dans ce dossier),
- le code source (`Modele 1`, `Modele 2`, etc.),
- les donnees lourdes dans un dossier separe (`donnees/`).
